# ByggExp — мобильное приложение

**Источник:** [карточка FL.ru](https://www.fl.ru/user/monnarxx/portfolio/8080768/).

**Описание:** Приложение для прорабов и рабочих: смены, задачи, документы, чаты и фотографии с объекта. Часть SaaS ByggExp.

**Мой вклад:** Основные экраны, GPS check-in/out, карта адреса проекта, камера и предпросмотр файлов; темы, уведомления по задачам, экспорт смен, регистрация, помощь, правила и баг-репорты.

**Технологии:** Expo, React Native, React Navigation, i18next, Axios, Sentry.

**Результаты:** метрики в карточке не указаны.
