# Enplug — приложение для экранов недвижимости

**Источник:** [карточка FL.ru](https://www.fl.ru/user/monnarxx/portfolio/7990056/).

**Описание:** Приложение системы Enplug показывает объекты недвижимости на экранах в холлах зданий, отелей и коммерческих объектов.

**Мой вклад:** Разработка приложения для демонстрации недвижимости на таких экранах.

**Технологии:** React, MobX, Webpack, Bootstrap 3, HTML5, CSS3.

**Результаты:** метрики в карточке не указаны.
